Confine the agent
nono: >..

Lock 1: nono confinement

The agent can write one request file to a write-only outbox. It cannot read the outbox, reach the network, call the executor, or access signing keys.

The watcher computes the request ID, digests, and policy version independently.

Authorize the action

Lock 2: EMILIA authorization

Two of three approvers sign a receipt for the exact action. The receipt binds the action and target, expires quickly, and can be used once.

A missing signature, changed action, expired receipt, or replay is denied.

Attest the node

Lock 3: Keylime attestation

The target must return a fresh Keylime PASS for the intended node. The workload and input bytes must match approved digests.

Execution uses verified file descriptors. Missing, stale, or failed attestation denies the request.
