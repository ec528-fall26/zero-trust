Zero trust confinement

An AI agent can ask for a job, but the job only runs if three locks open: the agent stays confined, two of three people approve that exact request, and the machine proves it's healthy. Use the buttons below and watch which lock stops each attempt.

Lock 1 · Confine the agent

The agent can only write one request file to a write-only outbox. It can't read it back, use the network, call the executor, or read signing keys. A trusted watcher rebuilds the request with its own IDs and hashes.

Lock 2 · Authorize the action

Two of three approvers sign an EMILIA receipt for this exact action and target. It expires quickly and works once. A missing signature, a changed action, or a replay is refused.

Lock 3 · Attest the node

Keylime must report a fresh PASS (under 30 seconds old) for the intended machine. The job's bytes must match the approved fingerprints, and IMA catches unapproved programs.
